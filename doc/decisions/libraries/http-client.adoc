= HTTP Client Library

[QUESTION]
====
Which library to use to make HTTP requests to other services?
====

[TIP]
====
Status: Accepted +
Created: 19.12.2025 +
Author: Seepick
====

*Context*

* We need to execute HTTP requests.

*Options*

.OkHttp
. Java native Http Client
. Apache Http Client
. Feign
. Ktor client
** Kotlin-idiomatic library with coroutine-first design
** Plugins for Content-negotiation, (JSON) serializer, Logging, Retry, etc.
** Kotlin multiplatform support (client SDKs possible)

*Decision*

* Ktor-client
* Fits the lightweight goal.
* Fits in with the rest of the Ktor&co stack.
