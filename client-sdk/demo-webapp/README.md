# Client-SDK Demo Webapp

Goal:

* Showcasing how a Kotlin multi-platform can facilitate reusable-code-sharing across backend and frontend.
* Instead of reading OpenAPI docs (and probably running out of sync), use a full fledged SDK implementing all explicit and implicit behaviors.
* Data objects, interface definition, and a ready to use client (using Ktor underneath) to easily use the backend API.

Implementation:

* Use the client-SDK project's JavaScript output to implement a TypeScript angular (MWP-FE like) demo application.
* FIGURE OUT how to use the library in TypeScript (unclear).
* Write a super simple CRUD-like application, focus on functionality in the code, not the UI; could be a plus for "impression management".
